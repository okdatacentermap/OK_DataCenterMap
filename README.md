# Northeast Oklahoma data centers — map & timeline

An interactive map and timeline of large data-center and industrial projects in northeast Oklahoma, centred on
Meta's Project Anthem in east Tulsa and the surrounding Fair Oaks MPD-6 development, and covering Google's Pryor and
Clydesdale sites, Projects Mustang and Spring, the Port of Inola smelter, Core Scientific and others. It shows zoning,
land records, site plans, permits, easements and power infrastructure. Every item links to its public source.

Built with [Leaflet](https://leafletjs.com/) on Esri World Imagery. The site is in `docs/`.
